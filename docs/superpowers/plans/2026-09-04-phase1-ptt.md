# Phase 1 — PttStateMachine Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver pure `PttStateMachine` seam per PRD US-01 (all ACs) and FR-08 — floor arbitration via control Frames (FLAG_PTT, payload_len=0), Channel Busy, debounce 80ms, and DUPLEX bypass, without Android KeyEvent, AudioManager, transport sockets, or UI.

**Architecture:** Single pure Kotlin class `data/ptt/PttStateMachine` operating on existing `domain/model/Frame` (`pttPressed`, `payloadText` empty, `mode`) and `TransmitMode`. States `PttState {Idle, Holding, Busy}` plus transient `Requesting` collapsed into immediate grant; `PttEvent` sealed (`SendControlFrame`, `FloorGranted`, `FloorDenied`, `FloorReleased`, `RemoteGranted`, `RemoteReleased`, `Debounced`, `Ignored`). Debounce via injectable `Clock`/`currentTimeMs` (default `System.currentTimeMillis`) with 80ms threshold. Generates control Frames with monotonic `seqId`, empty payload, correct `pttPressed` — round-trippable via existing `FrameCodec`. No Android deps, deterministic host-testable.

**Tech Stack:** Kotlin 1.9.22, JUnit 4.13.2 + Truth, Android SDK 34 arm64-v8a only, CMake/ASAN unchanged, manifest 11 permissions no INTERNET.

**Spec:** `docs/PRD.md` §2.2 US-01 AC-01.1 (PTT button+VOLUME_DOWN, debounce 80ms), AC-01.2 (12-byte control frame `FLAG_PTT=1/0` `payload_len=0`), AC-01.3 (VAD while floor held — deferred), AC-01.5 (Channel Busy), §2.2 US-02 AC-02.3 (DUPLEX ignores PTT), §4.1.1 `transport/protocol` interaction (FrameCodec Appendix B bit5), `docs/Offline Multilingual Speech Transceiver Architecture.md` PTT/floor-control §172-189, baselines `089f53e` FrameCodec, `72ad685` VadFsm, `e8a50dc` PriorityRouter.

```kotlin
class PttStateMachine(
  private var mode: TransmitMode = TransmitMode.HALF_DUPLEX,
  private val clock: ()->Long = { System.currentTimeMillis() },
  private val debounceMs: Long = 80
) {
  private var state=PttState.Idle
  private var lastEventMs: Long = -1000
  private var seq=0
  private fun now()=clock()
  private fun nextSeq()=seq++ and 0xFFFF
  private fun controlFrame(ptt:Boolean)=Frame(mode,false,false,ptt,Language.HINDI,Language.ENGLISH,nextSeq(),"")
  fun onLocalPress(): PttEvent { if(mode==TransmitMode.DUPLEX) return PttEvent.Ignored; val t=now(); if(t - lastEventMs < debounceMs) return PttEvent.Debounced; lastEventMs=t; return when(state){ PttState.Idle -> { state=PttState.Holding; val f=controlFrame(true); PttEvent.SendControlFrame(f)}; PttState.Busy -> PttEvent.ChannelBusy; else -> PttEvent.FloorDenied } }
  fun onLocalRelease(): PttEvent { if(mode==TransmitMode.DUPLEX) return PttEvent.Ignored; val t=now(); if(t - lastEventMs < debounceMs) return PttEvent.Debounced; lastEventMs=t; return when(state){ PttState.Holding -> { state=PttState.Idle; val f=controlFrame(false); PttEvent.FloorReleased(f)}; else -> PttEvent.Ignored } }
  fun onRemoteFrame(frame: Frame): PttEvent { if(mode==TransmitMode.DUPLEX) return PttEvent.Ignored; if(frame.payloadText.isNotEmpty()) return PttEvent.Ignored; return if(frame.pttPressed){ state=PttState.Busy; PttEvent.RemoteGranted } else { if(state==PttState.Busy) state=PttState.Idle; PttEvent.RemoteReleased } }
  fun currentState()=state
  fun isFloorHeldLocally()=state==PttState.Holding
  fun clear(){ state=PttState.Idle; lastEventMs=-1000; seq=0 }
}
```

Policy: Half-duplex only. Debounce uses injectable clock. Control frames empty payload, FLAG_PTT correct, monotonic seq. Remote frames with non-empty payload ignored for PTT (text frames). DUPLEX returns `Ignored` and never changes state.
