### Task 3: TDD GREEN — Kotlin VadFsm (Host-testable)

**Files:**
- Create: `app/src/main/java/com/itantra/data/vad/VadFsm.kt`

**Interfaces:**
- Consumes: `VadState` + test expectations
- Produces: Passing `VadFsm` that satisfies all 16 tests, pure (no Android, no ONNX)

Logic (mirrors C++):
- Config: `hangoverMs` default 450, `frameMs` 30 → `hangoverFrames = hangoverMs / frameMs` (15 for 450), `preRollMs` 200 → `preRollFrames` 7 (ceil 200/30) or 3200 samples circular buffer.
- State vars: `state`, `consecutiveOnset =0`, `pauseCounter=0`, `preRoll: ArrayDeque<ShortArray>`, `utterance: MutableList<Short>`
- `onFrame(prob, pcm)`:
  1. push `pcm` into `preRoll` (bounded size 7) while Idle.
  2. if Idle: if prob≥0.6 → `consecutiveOnset++` else 0; if ≥3 → flush preRoll into utterance + current frame, `state=Speaking`, reset counters.
  3. if Speaking: append pcm to utterance; if prob<0.35 → `state=Pause`, `pauseCounter=1` else stay Speaking.
  4. if Pause: if prob≥0.35 → append pcm, `state=Speaking`, `pauseCounter=0`; else `pauseCounter++` (do NOT append silence); if `pauseCounter * frameMs >= hangoverMs` → `state=Eou` (do not append).
  5. if Eou: caller must call `getUtterance()` then `reset()` to return to Idle (tests assert Eou then Idle after reset).
- `getUtterance()` returns copy of buffered speech (preRoll+speech, trimmed), `reset()` clears all.
