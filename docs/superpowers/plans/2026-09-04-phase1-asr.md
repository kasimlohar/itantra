**Architecture:** Keep `data/asr/AsrEngine.kt` interface unchanged (`load(Language):Result<Unit>`, `unload()`, `isReady()`, `isLoaded()`, `transcribe(ShortArray,Language):Result<String>`). New `SherpaAsrEngine` (Kotlin, `data/asr/SherpaAsrEngine.kt`) wraps `com.k2fsa.sherpa.onnx.OfflineRecognizer` (sherpa-onnx 1.10+ AAR `net.java.dev.jna`/`onnxruntime` via `sherpa-onnx` Maven) with `OfflineRecognizerConfig` (modelDir `assets/models/stt/hi`, `tokens.txt`, `model.onnx` INT8, `numThreads=2`, `provider="cpu"`). Optional C++ `cpp/asr/sherpa_asr_engine.h/.cpp` mirrors `AsrEngine` (load/unload/transcribe) for later NDK path, but Kotlin is primary for this slice. `ModelManager` remains pure; `SherpaAsrEngine` collaborates but does not bypass it — `load()` checks file existence, creates recognizer, registers with `ModelManager` via caller. Tests drive `SherpaAsrEngine` directly and via `ModelManager` (only one STT).

**Tech Stack:** Kotlin 1.9.22, sherpa-onnx 1.10.1 Android AAR (`com.k2fsa.sherpa: sherpa-onnx` or `net.java.dev.jna:jna` + `onnxruntime`), JUnit 4.13.2 + Truth, NDK arm64-v8a ASAN/UBSAN, Hindi model `indic_conformer_hi_int8.onnx` + `tokens.txt` (~130 MB, CC-BY-4.0, from `trysem/indicconformer-120m-onnx` or `ai4bharat`).

class SherpaAsrEngine(private val context: Context, private val modelManager: ModelManager? = null) : AsrEngine {
  private var recognizer: OfflineRecognizer? = null
  private var loadedLang: Language? = null
  override fun load(language: Language): Result<Unit> {
    if (loadedLang==language && recognizer!=null) return Result.success(Unit)
    unload()
    val modelDir = "models/stt/${language.name.lowercase()}/indic_conformer_${language.name.lowercase()}_int8.onnx"
    // check assets exists, create OfflineRecognizerConfig, OfflineRecognizer.from_nemo_ctc
    // handle JNA load, numThreads=2, provider cpu
    // on success loadedLang=language, return success else failure
  }
  override fun transcribe(pcm: ShortArray, language: Language): Result<String> {
    if (!isReady() || !isLoaded(language)) return Result.failure(IllegalStateException("NotReady"))
    if (pcm.isEmpty()) return Result.failure(IllegalArgumentException("EmptyAudio"))
    val stream = recognizer!!.createStream()
    stream.acceptWaveform(pcm.map{ it/32768f }.toFloatArray(), 16000)
    recognizer!!.decode(stream)
    return Result.success(stream.result.text)
  }
  // unload/isReady/isLoaded as per interface, delegate to ModelManager if present
}
