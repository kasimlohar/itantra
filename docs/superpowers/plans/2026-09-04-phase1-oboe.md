# Phase 1 — Oboe Capture Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Connect real microphone to existing lock-free `SpscRingBuffer<int16_t>` via Oboe 1.8+ (16 kHz mono, low-latency, `SCHED_FIFO`-friendly callback → ring buffer), without adding STT/TTS, transport, or UI, keep callback GC-free/lock-free.

**Architecture:** New C++ `audio::AudioCapture` owning `SpscRingBuffer<int16_t> (8192 ≈512 ms, ≥200 ms pre-roll)` and `oboe::AudioStream*` (input). `AudioCapture` exposes `bool start()`, `void stop()`, `bool isCapturing() const`, `SpscRingBuffer<int16_t>& ring()` and `bool pop(int16_t* out, size_t n)` for VadFsm consumer. Oboe `AudioStreamCallback` (`onAudioReady`) is `SPSC` producer: copies `int16_t` frames directly into ring via `ring.push(data, numFrames)` — no `new`/`malloc`, no `log`, no JVM calls. `CMakeLists.txt` adds `oboe` via `FetchContent` `1.8.1` and links `oboe::oboe` + `log` to `itantra-native`; host `BUILD_TESTING` keeps same but `AudioCapture` tests mock Oboe (no device needed). Kotlin thin `data/audio/AudioCaptureController` (optional) just delegates `start/stop` via JNI.

**Tech Stack:** C++17, CMake 3.22.1, Oboe 1.8.1 (FetchContent `https://github.com/google/oboe/archive/refs/tags/1.8.1.zip`), NDK r26 clang, GTest 1.14, Kotlin 1.9.22, `SpscRingBuffer` existing header-only, ASAN/UBSAN via `SANITIZE`, 11 permissions no INTERNET.

**Spec:** `docs/PRD.md` FR-11 `Native audio via Oboe, GC-free, lock-free ring, no underruns on 90 s`, §4.1.1 `audio-io` seam `AudioCapture::RingBuffer {push(PCM16),pop(30ms),preRoll(200ms)}`, §4.1.3 `Audio thread SCHED_FIFO lock-free ring never on JVM`, `docs/Offline Multilingual Speech Transceiver Architecture.md` audio-capture / Oboe / ring-buffer (16 kHz 480/30 ms, 200 ms pre-roll), baseline 124 tests (109 Kotlin +15 native) green.

**Interfaces:**

Sketch (no allocs in callback):

```cpp
#include "audio/audio_capture.h"
#include <oboe/Oboe.h>
using namespace itantra::audio;
AudioCapture::AudioCapture(size_t cap): ring_(cap), stream_(nullptr), capturing_(false) {}
AudioCapture::~AudioCapture(){ stop(); }
bool AudioCapture::start(){
 if(capturing_) return true;
 oboe::AudioStreamBuilder b;
 b.setDirection(oboe::Direction::Input)->setSampleRate(16000)->setChannelCount(1)
  ->setFormat(oboe::AudioFormat::I16)->setPerformanceMode(oboe::PerformanceMode::LowLatency)
  ->setSharingMode(oboe::SharingMode::Exclusive)->setCallback(this)->setFramesPerCallback(480);
 oboe::Result r=b.openStream(&stream_);
 if(r!=oboe::Result::OK) return false;
 r=stream_->requestStart(); if(r!=oboe::Result::OK){ stream_->close(); stream_=nullptr; return false; }
 capturing_=true; return true;
}
void AudioCapture::stop(){ if(stream_){ stream_->requestStop(); stream_->close(); stream_=nullptr; } capturing_=false; }
bool AudioCapture::isCapturing() const { return capturing_; }
oboe::DataCallbackResult AudioCapture::onAudioReady(oboe::AudioStream*, void* audioData, int32_t numFrames){
 if(audioData && numFrames>0) ring_.push(static_cast<int16_t*>(audioData), numFrames);
 return oboe::DataCallbackResult::Continue;
}
SpscRingBuffer<int16_t>& AudioCapture::ring(){ return ring_; }
void AudioCapture::clear(){ ring_.clear(); }
```

No `__android_log_print` in `onAudioReady`, no `new`, no mutex.
